# Manajemen Produk

Aplikasi React sederhana untuk mengelola daftar produk dan harga.

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

## Fitur

- Menampilkan lima produk awal beserta harga dalam Rupiah.
- Mencari produk berdasarkan nama.
- Menambah, mengubah, dan menghapus produk melalui dialog konfirmasi.
- Memvalidasi nama produk dan harga lebih dari Rp0.
- Menyimpan perubahan di `localStorage` browser.
